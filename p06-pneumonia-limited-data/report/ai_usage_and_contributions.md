## 3. Human Intellectual Contribution (What the Group Did)
The group members conceived, designed, implemented, and verified all core deep learning aspects of the project:
- **Problem Formulation:** Selected Project P06 and framed the central scientific question: evaluating how transfer learning with staged progressive unfreezing compensates for severe label scarcity (25% training data budget).
- **Experimental & Protocol Design:** Enforced strict methodological integrity: single generation of the stratified 25% subset (`train25_seed42.json`), validation-only model selection, and one-time test split evaluation guarded by filesystem markers (`test_eval_done.json`).
- **Baseline Architecture:** Defined and justified the reference 3-block convolutional neural network (Conv-ReLU-MaxPool x3 + GAP + FC) trained strictly from random initialization without modern regularizers.
- **Proposed Solution:** Conceived and implemented the 3-stage fine-tuning schedule on ImageNet-pretrained ResNet-18 (head -> layer4 -> full network) with discriminative layer learning rates, domain-appropriate augmentations (no horizontal flips to preserve thoracic anatomical orientation), subset class weighting, and label smoothing.
- **Verification of Results:** Every reported metric, confusion matrix count, AUROC, ECE, and bootstrap confidence interval was computed directly by project evaluation code from saved prediction files. No results or metrics were fabricated.
